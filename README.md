# Batoot Casino v2

نسخة نظيفة مبنية على Discord.js v14، مع حفظ دائم للأرصدة والرهانات وطلبات السحب.

## التشغيل
1. استخدم Node.js 18.17 أو أحدث.
2. نفّذ npm install.
3. أضف DISCORD_TOKEN في متغيرات الاستضافة.
4. فعّل Message Content Intent من Discord Developer Portal.
5. شغّل npm start.

## الإعدادات
- OWNER_ID: الأونر، الافتراضي 1483368871032520704.
- GUILD_ID: السيرفر، الافتراضي 1501507950492127234.
- GAME_CHANNEL_IDS: رومات الألعاب مفصولة بفواصل.
- WITHDRAW_PANEL_CHANNEL_ID: روم لوحة السحب.
- WITHDRAW_REQUESTS_CHANNEL_ID: روم مراجعة الطلبات.
- ADMIN_IDS: آيديّات إداريين إضافيين مفصولة بفواصل.
- PROBOT_ID: آيدي بوت ProBot، الافتراضي 282859044593598464.
- PROBOT_OWNER_IDS: آيديّات حسابات استقبال التحويل مفصولة بفواصل؛ الافتراضي 992561603046293596 (حساب استقبال التحويل المستخدم في النسخة القديمة).
- DISCORD_TOKEN: توكن البوت (مطلوب).

## الأوامر
- فلوس أو money: عرض الرصيد.
- توب أو top: أعلى 10 أرصدة.
- تحدي @عضو مبلغ: بدء تحدٍ في رومات الألعاب المحددة.
- withdraw: نشر لوحة السحب في روم السحب.
- add @عضو مبلغ و rmv @عضو مبلغ: للأونر والإدارة فقط.
- مساعدة: عرض الأوامر.

## الألعاب
- النرد: كل لاعب يرمي مرة واحدة، والأعلى يفوز.
- الرقم التقريبي: كل لاعب يختار رقماً، والأقرب للرقم السري يفوز.
- رسوم الفوز 4%. التعادل يعيد الرهانين.
- الرهانات تُحجز عند قبول التحدي وتُعاد تلقائياً عند انتهاء المهلة.

## السحب
طلب السحب يحجز الكوينات حتى تراجع الإدارة. الرفض يعيد الرصيد. الموافقة تسجل القرار فقط؛ التسليم الخارجي يدوي من الإدارة.

## البيانات والأمان
- تُحفظ البيانات في data/store.json.
- عند أول تشغيل يستورد البوت الأرصدة من data/databaseusers.json القديمة أو db.json إن وجدت.
- لا تحذف مجلد data عند إعادة النشر.
- شحن الرصيد عبر تحويل ProBot إلى حساب استقبال مضبوط في PROBOT_OWNER_IDS.
- لا ترفع ملف .env أو توكن البوت إلى GitHub.
- الأرصدة افتراضية داخل البوت؛ لا يوجد دفع أو تحويل أموال حقيقي مدمج.
