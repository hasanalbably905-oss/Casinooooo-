# Golden Dice Bot

## التشغيل
1. `npm install`
2. ضع التوكن في متغير البيئة:
   - Linux/Mac: `export DISCORD_TOKEN="your_token"`
   - Windows PowerShell: `$env:DISCORD_TOKEN="your_token"`
3. `npm start`

## ملاحظات
- فعّل Message Content Intent من بوابة المطورين في Discord.
- الأرصدة تُحفظ في `db.json` (غير مرفوع على GitHub).
